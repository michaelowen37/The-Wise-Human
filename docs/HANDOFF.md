## Where things live

- src/logic.mjs: modules, courses, generators, rules, mastery, rounds (`buildAttempt`), experiments, life skills, games and decks, titleCase, spreadLeads, sprintPool, and (pass FR) the Story Log's lists (`storyLogAvailable`, `recentReads`) and the book's pages (`bookPages`, `printParts`). src/curriculum.mjs: the standards plan. src/stories.mjs: STORIES by module id (S serials, `more` pictures with `after` paragraph indexes), COURSE_STORIES by course id (CS serials), COURSE_GOALS (the one-line subtitle on a printed cover). src/ui.jsx: every screen, the print styles (the story book is body.edu-book-mode: zero page margin, fixed-height page groups with inner padding so the sky prints to the edge), the crash guard, the test hooks on window.__eduTest (openModule, openStory, goTo, crash, visibleModuleIds, goHome).

- tools/stories/batch.py and batch-example.py: the story batch driver. tools/story-length.mjs, tools/story-arc.mjs, tools/prompts-csv.mjs, tools/map-overlay.mjs, tools/untaught.mjs: reports and helpers.
